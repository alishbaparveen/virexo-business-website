# 🚀 Virexo — Business Website Expansion

A modern, responsive business website developed for **Virexo Innovations** as part of the **Week 2 Web Development Internship Program**.

The website presents Virexo Innovations as a digital solutions company providing **Web Development, AI & Machine Learning, Python Development, and Graphic Design** services.

---

## 🌐 Project Overview

**Virexo — Business Website Expansion** is an improved version of the Week 1 homepage.

The goal of Week 2 was to transform the basic homepage into a more complete, professional, and business-focused website with clear service sections, company information, responsive navigation, and strong calls-to-action.

## ▶️ Run the Project Locally

Since this is a static website, you can open `index.html` directly in your browser.

Alternatively, run a local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🚀 Deployment

This project can be deployed using any static hosting platform.

### GitHub Pages

```bash
git init
git add .
git commit -m "Virexo - Business Website Expansion"
git branch -M main
git remote add origin <your-repository-url>
git push -u origin main
```

After pushing the project:

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Choose **Deploy from branch**.
5. Select the `main` branch.
6. Save the settings.

GitHub will provide your live website URL.
